# 칼 카드 일러스트

칼이 진화할 때마다 여기 있는 그림이 카드로 공개된다.

## 파일 이름

```
public/cards/ku/0.png ~ 4.png    고려대 칼 1~5단계
public/cards/yu/0.png ~ 4.png    연세대 칼 1~5단계
```

번호는 칼 단계와 같다. `0.png` 가 낡은 연습검, `4.png` 가 최종 단계다.

파일이 없으면 카드 자리에 단계 이름만 있는 대체 화면이 나온다. 그래서 그림이
하나도 없어도 게임은 그대로 돌아가고, 준비되는 것부터 하나씩 넣으면 된다.

## 권장 사양

- 세로형 3:4 비율 (예: 900 x 1200)
- PNG, 배경 투명 또는 단색
- 한 장당 300KB 이하 — 행사장 네트워크가 좋지 않을 수 있다
- 픽셀 아트라면 확대해도 뭉개지지 않도록 원본 배율 그대로 저장한다
  (CSS에서 `image-rendering: pixelated` 를 적용해 둠)

## 카드 문구와 크레딧

카드 이름·설명·그린 사람 표기는 `lib/cards.ts` 에서 고친다.
`ARTISTS` 배열에 이름을 넣으면 카드 하단에 "그림 ○○○" 이 표시된다.

## 저작권

넣는 그림은 사용 권한이 확실한 것만 쓴다. 직접 그렸거나, 외주로 이용 범위를
계약한 것이어야 한다. 학교 공식 로고·마스코트를 쓸 경우 별도로 사용 허가를
확인한다.
